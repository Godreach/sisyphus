# 0026 - 可选 S3 构建产物空间与制品库入口

状态：已接受

## 决策

制品库是按项目聚合浏览历史构建产物的一级入口，不是包仓库，也不提供跨构建依赖或“最新版本”解析。每次构建有独立产物空间，内部按任务、执行 attempt 与上传声明区分产物集；目录保留相对结构。S3 兼容后端由部署者自行提供和运维，是这项入口的可选前提。未配置时入口提示不可用，既有单文件构建产物仍在 Server 本地存取并沿用原 30 天保留期；配置后，新构建产物集写 S3、默认永久保留，旧本地产物不自动迁移。日志不是产物，不出现在制品库中。

Server 的数据库是产物目录、项目归属和授权的事实源。Server 持有长期 S3 凭据；Agent 和用户经 Server 授权取得针对具体对象的短期预签名 URL，直接与 S3 传输字节。Agent 只可按任务声明上传清单内的文件，不获得构建前缀的通用凭据。上传先进入临时 key，Server 校验内容后复制到从未签发写权限的最终 key，再原子发布 ready 产物集；未完成上传、删除及外部对象改动均不能被当作正常 ready 内容。大对象使用 multipart 上传与 multipart copy。

## 理由与取舍

构建产物仍是一次构建内的任务交换与历史记录，不需要包版本模型；保留本地默认模式也维持了零外部依赖的基本流水线能力。直传避免 Server 中转数 GiB 文件，代价是 S3 endpoint 必须同时可被 Server、Agent 和下载者访问。临时/最终 key 的复制增加存储 I/O 和 S3 兼容门槛，但消除了旧预签名写 URL 对 ready 对象的改写能力。自托管责任由部署者承担，软件验证 API 契约而不识别或封禁特定服务商。
