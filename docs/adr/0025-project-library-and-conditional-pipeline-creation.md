# 项目库独立导航与流水线条件首建

日期：2026-09-16
状态：已接受

依据 #116 的[创建流程规格](../specs/project-library-and-pipeline-creation.md)及 #117–#120 的实现，项目库作为独立集合入口，项目详情归项目库，流水线列表、编辑器和构建归流水线；编辑器的返回位置单独保存创建来源，不由导航高亮或面包屑推断。

对 ADR-0023「编辑器只换视觉」作创建相关的增量：三个创建入口复用同一对话框，以显式新建标记进入混合式编辑器的内存草稿。首次保存前无服务端记录、修订版本或构建；首次保存携带 `If-None-Match: *`，数据库用唯一键与单条 INSERT 原子裁决不存在条件，成功修订为 1，失败同名返回 412 并保留草稿。客户端不将失败的首建降级为覆盖保存，用户可改名重试或主动打开已有流水线。

保留 ADR-0006 的普通编辑修订语义和 ADR-0020 的派生轨道/属性表单，不新增草稿领域实体、持久化草稿、自动保存或预创建请求。已修改的新建草稿离开须由用户确认，刷新/关闭使用浏览器原生提示；首次创建成功后清除新建标记，后续无条件 PUT 仍兼容既有 upsert。
