# 0011 - Agent 工作区隔离与生命周期

日期：2026-08-15
状态：已接受

## 背景

ADR-0002 已定默认宿主机直跑，要求「每次构建独立工作区目录」的隔离策略；ADR-0006 定了从失败任务重跑复用工作区（同号 attempt+1）；ADR-0008 定了进程树终止与离线续跑语义。本票定 Agent 侧工作区模型：目录粒度、checkout 语义、清理策略、与缓存目录的边界、跨 Agent 独立性、根目录布局，以及两条对既有 ADR 的补丁。盘问过程见 [wayfinder 票 #17](https://github.com/Godreach/sisyphus/issues/17)。

## 决策

**粒度**：工作区 per job--`<工作区根>/<pipeline>/<job>/`，pipeline 名仅作归组（人工浏览、按 pipeline 清理）。同一 job 的再次构建与从失败任务重跑天然复用同一工作区；job 改名视为新工作区，旧的按清理策略回收。阶段内并行 job 各有目录，同机多槽不冲突。

**checkout 语义**：复用工作区上的 `checkout scm` 一律增量：fetch 已有仓库 + checkout 目标 commit + 清理未跟踪的非忽略文件（`clean -fd` 语义）；不删 `.git`，不碰 gitignore 的本地文件。v1 固定此策略，不暴露 job 级 clean 配置；脏工作区的逃生口是 UI 手动清理。

**清理**：仅 UI 手动清理（per-agent 工作区列表，单个删除或全清，经 gRPC 指令下发）。无保留条数、无磁盘水位触发的自动清理、无后台扫描删除。清理工作区永不触碰缓存目录。

**缓存边界**：缓存目录在工作区之外（`<agent 数据根>/cache/<key>/`），key 设计、命中与淘汰规则归缓存票 #12。理由：增量 checkout 的 clean 会误删工作区内缓存；「清工作区、保缓存」是手动清理的直觉预期。

**跨 Agent**：各 Agent 的工作区树完全独立，不共享、不同步。同一 job 被调度到不同 Agent 时各建各的工作区；跨平台标签矩阵（同名 job 在不同 OS）天然各归各机。Server 与用户对「哪台机器有遗留工作区」无感知。

**根目录与命名**：工作区根 = 环境变量 `SISYPHUS_AGENT_WORKSPACE_ROOT` 优先，缺省 `<agent 数据根>/workspaces/`（Unix `~/.sisyphus-agent/`，Windows `%USERPROFILE%\.sisyphus-agent\`）。目录名 = pipeline/job 名清洗：非 `[A-Za-z0-9._-]` 一律替换为 `_`，冲突时追加 id 后缀。`SISY_WORKSPACE` 内置变量 = job 工作区目录绝对路径。

**变量解析补丁（ADR-0006）**：`${SISY_WORKSPACE}` 以占位符随任务规格下发，Agent 在执行任何步骤前完成替换；其余 7 个内置变量与用户参数仍由 Server 端解析。when 表达式禁用 `SISY_WORKSPACE` 不变（ADR-0009）。

**离线回归补丁（ADR-0008）**：宽限超时判败后原 Agent 重连、本地任务仍在跑时--Agent 上报在途任务，Server 告知已判终态，Agent 本地终止并丢弃；重跑任务下发时 Agent 检查目标工作区无残留进程记录。竞态窗口极窄，v1 不做本地工作区锁（锁文件在进程被强杀后反成新的脏状态来源）。

**隔离强度**：v1 仅目录级隔离，并发任务间无 OS 用户/权限边界；文档建议管理员以专用低权限服务账号运行 Agent（整机一刀切，非 per-job）。

## 理由

- per job 而非 per build：从失败任务重跑复用工作区（ADR-0006）要求目录跨 attempt 稳定；per pipeline 会在阶段内并行时互相踩踏。job 改名导致缓存重置是可接受代价，语义永远清晰优先。
- 仅手动清理：后台扫描/水位自动清理都有误删「正在被复用的工作区」的窗口（用户重跑三天前的失败任务前夜被清）；~100 台自有构建机规模下手动清理是可接受的运营成本。
- 占位符下发：工作区根是 per-Agent 配置，Server 下发前不可能知道绝对路径；让 Server 推算路径需要两端共享命名规则，脆且 when 禁用已定，无收益。

## 后果

- Agent workspace 模块（ADR-0009）需实现：目录布局与名称清洗、增量 checkout、手动清理指令处理、`${SISY_WORKSPACE}` 占位符替换、重跑前残留进程检查。
- 通道（ADR-0007 的 proto）需覆盖：工作区列表查询与清理指令两类消息。
- ADR-0006 的内置变量表述修正为「7 个 Server 解析 + 1 个（SISY_WORKSPACE）Agent 解析」；ADR-0008 增补「重连发现已判终态则本地终止丢弃」语义。
- #12（缓存）获得边界约束：缓存根独立于工作区根。
- #13（容器后端）获得挂载接口：容器任务挂载同一 job 工作区。
- 磁盘占用上报归 #19（可观测性）处置，本票不展开。
