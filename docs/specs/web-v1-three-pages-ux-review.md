## 复核后排除的疑点（记录避免重查）

- 「最近流水线『运行』按钮与行错位、触发到错误流水线」：**不成立**。系自动化操作坐标伪影；DOM 级验证按钮与行绑定正确（`OverviewView.vue` v-for 直绑 `p.project/p.pipeline`）。
- 「toast 全局失效」：**不成立**。`n-message-provider` 正常挂载，终止/触发 toast 均出现；此前误报为探测时机与操作坐标问题。
- 流水线页「共 22 条」与工作台「179 次构建」数字差异：口径不同（流水线条目 vs 构建次数），非缺陷。

## 已验证正常的部分（抽查）

- 登录 → 会话恢复 → 三页导航；中/EN 即时切换（含 nav/列头/按钮文案）。
- 流水线：筛选 chip 单选、列表/卡片视图切换、排序（最近运行/名称）、搜索（匹配流水线+项目名）、行名进构建列表、排队行「终止」后行内刷新。
- 构建机：四态+停用+构建中+版本不兼容徽章齐全；停用机器 CPU/内存「—」正确（M5 是离线未停用的场景）；接入构建机空态指引（外链直入时弹窗正常）。
- 错误纪律：错误态 fixture（error-demo）与整页报错+重试在多个页面就位。
